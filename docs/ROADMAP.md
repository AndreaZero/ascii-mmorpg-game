# Roadmap

Build a distinctive, readable world first. Add systems one at a time and assess them in the prototype before expanding the scope. The order below is a direction, not a release schedule.

## Available now

- [x] Procedural dark fantasy clearing with ruined stonework and water.
- [x] Surface-attached glyphs and animated glyph vegetation.
- [x] Planar water reflections and warm local lighting.
- [x] Camera-relative movement, orbit, zoom and character inspection.
- [x] First procedural idle / walk / run pass with planted feet.
- [x] Locomotion checks and public project documentation.

## 1. Character polish — current focus

- [ ] Refine silhouette and leg readability from normal gameplay distance.
- [ ] Improve turns, starts, stops and changes of direction.
- [ ] Refine foot placement along shore transitions and uneven ground.
- [ ] Tune cape, arms and lantern motion together.

Success means the character feels grounded at normal camera distance, and its movement stays readable through ASCII materials.

## 2. Environment identity

- [ ] More varied trees, rocks and ruin silhouettes.
- [ ] Better glyph stability at different zoom levels.
- [ ] Refine water, lighting and atmospheric motion.
- [ ] Repeatable performance measurements on additional hardware.

## 3. Local gameplay foundation

- [ ] Interactions and feedback in a small playable loop.
- [ ] A first focused combat experiment with readable attacks.
- [ ] Audio, basic progression and local save/load.
- [ ] Packaged prototype builds once the experience is ready to share.

## 4. Multiplayer research

- [ ] Test authoritative movement in a small shared area.
- [ ] Evaluate synchronization, latency and persistence.
- [ ] Choose infrastructure from measured requirements.

Large worlds, economy, guilds and MMO-scale concurrency depend on those experiments. They are ambitions, not implemented or scheduled features.
